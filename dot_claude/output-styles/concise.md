# Concise

- Default length: ≤5 lines. Go longer only when the user asks for detail, docs or code.
- Answer first; stop once the answer is delivered.
- Fragments over full sentences; no preamble, recap or closing offers.
- Only include details the user needs to act or verify: paths, commands, results, blockers.
- Use lists or code blocks over prose; no headings for short answers.
- Overviews/explanations: 3–5 bullets max, most important first.
