# Dotfiles (macOS)

Minimal [chezmoi](https://www.chezmoi.io/) setup for a new Mac: Homebrew packages, Ghostty (Catppuccin light/dark), mise, and a few OS defaults.

## Bootstrap (fresh Mac)

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/llstarscreamll/dotfiles/master/bootstrap.sh)"
```

That installs Homebrew (if needed), clones this repo to `~/.dotfiles`, installs chezmoi, and runs `chezmoi init --apply`. The first run asks for your name, personal email and work email (stored in `~/.config/chezmoi/chezmoi.toml` from [`.chezmoi.toml.tmpl`](.chezmoi.toml.tmpl), used by the git config). It ends by generating an SSH key (see below).

Already cloned locally? `./bootstrap.sh` from the repo root works the same.

## Day-1 packages

| Package | Via |
|---------|-----|
| mise | brew |
| Ghostty | brew cask |
| JetBrainsMono Nerd Font | brew cask |
| tmux | brew |

Ghostty uses **Catppuccin Mocha** (dark) / **Latte** (light) and follows the system appearance. tmux ([`dot_config/tmux/tmux.conf`](dot_config/tmux/tmux.conf)) uses only the terminal's ANSI colours, so it follows whatever theme Ghostty shows.

Also applies: faster key repeat, disables Ctrl+Arrow Mission Control shortcuts, clears the Dock, Touch ID for `sudo` (`/etc/pam.d/sudo_local`, works inside tmux via `pam-reattach`).

Scrolling: natural on the trackpad, classic on mice. macOS has one switch for both, so [LinearMouse](https://linearmouse.org/) reverses mouse scrolling ([`dot_config/linearmouse/linearmouse.json`](dot_config/linearmouse/linearmouse.json)). Grant it Accessibility access and enable "Start at login" once.

## Add more tools later

1. Edit [`Brewfile`](Brewfile) (e.g. `cask "cursor"`, `brew "neovim"`).
2. Run `chezmoi apply` (re-runs brew bundle; also updates `~/Brewfile`).

Agent skills (Claude Code, Cursor, opencode): add a `<repo> <skill>` line to [`Skillfile`](Skillfile) and run `chezmoi apply`.

AWS skills and the AWS MCP server come from `aws configure agent-toolkit --yes` (run once by `chezmoi apply`). Update them with `aws agent-toolkit update-skill --all`; find more with `aws agent-toolkit search-skills --search-query <query> --region us-east-1`.

Own skills live in [`dot_agents/skills/`](dot_agents/skills/) (`~/.agents/skills/`, read by Cursor and opencode). Claude Code needs a matching symlink in [`dot_claude/skills/`](dot_claude/skills/): a `symlink_<skill>` file containing `../../.agents/skills/<skill>`.

Global agent instructions live in [`dot_config/agents/AGENTS.md`](dot_config/agents/AGENTS.md) (`~/.config/agents/AGENTS.md`), shared by Claude Code (imported from `dot_claude/CLAUDE.md`), opencode (symlinked from `dot_config/opencode/`) and cursor-agent.

herdr integrations (Claude Code, opencode) are installed by `herdr integration install`, not tracked: herdr rewrites its hook files on update. The hook entry in [`dot_claude/settings.json.tmpl`](dot_claude/settings.json.tmpl) uses the exact command herdr writes, so reinstalling doesn't duplicate it.

Scripts share snippets from [`.chezmoitemplates/`](.chezmoitemplates/) (e.g. `{{ template "brew-env" . }}`).

Managed configs live as chezmoi source files (`dot_zshrc`, `dot_config/...`). Add new ones with:

```bash
chezmoi add ~/.config/herdr/config.toml
```

## Useful commands

```bash
chezmoi diff
chezmoi apply
chezmoi cd          # open source dir
chezmoi source-path
```

## SSH key (GitHub / Bitbucket)

Generated by the last bootstrap step ([`run_once_after_99-ssh-key.sh`](.chezmoiscripts/run_once_after_99-ssh-key.sh.tmpl), skipped if `~/.ssh/id_ed25519` exists): asks for a passphrase, stores it in the macOS Keychain and copies the public key to the clipboard. [`private_dot_ssh/private_config`](private_dot_ssh/private_config) loads the key into the agent from the Keychain.

Paste it in [GitHub → SSH keys](https://github.com/settings/ssh/new) or [Bitbucket → SSH keys](https://bitbucket.org/account/settings/ssh-keys/), then verify:

```bash
ssh -T git@github.com
ssh -T git@bitbucket.org
```
